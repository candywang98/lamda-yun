## 1. 最终架构决定

正式执行链路必须保持为：

```text
Web 工作台 -> Control API -> 手机 Companion APK
             -> APK 本地任务队列 -> Accessibility 本地执行器
             -> APK 本地日志/结果 outbox -> Control API 回传
```

Edge、ADB、USB 和投屏仅用于安装、开发和调试，不属于生产执行链路。最终验收必须在停止电脑
Edge、停止 ADB 并拔掉 USB 后，由公网工作台下发任务，手机独立接收、执行并回传。

## 2. 目录说明

- `apps/web`：Web 工作台。
- `apps/studio`：手机自动化调试 Studio。目前是受控调试 UI，不是完整的公网服务端 runner。
- `services/control-api`：Control API、数据库模型、Alembic migration、移动端任务接口。
- `mobile/companion`：手机 Companion APK，包含前台服务、任务同步、SQLite 队列、无障碍执行器。
- `mobile/acceptance-target`：用于真机闭环验收的目标 APK。
- `mobile/dpc`：设备策略相关 APK，不是手机自动化执行器。
- `contracts`：跨端结构化任务合同及测试数据。
- `docs`：架构、交付进度、部署和验收文档。
- `infra`、`scripts`：部署、OpenAPI 和辅助脚本。
- `edge`、`lab`：历史/调试链路代码；不得作为正式执行依赖。
