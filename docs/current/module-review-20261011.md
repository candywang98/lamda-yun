# 当前模块梳理（2026-10-11）

本次仅移除“产品介绍”与“更新日志”的用户入口、旧链接和页签；其他条目的处理建议尚未执行。

## 口径

移除后仍有15个运营分组、132个目录条目。原有4个停用条目仍不显示，因此默认菜单/全部功能展示128项，用户显示设置可能进一步减少数量。另有设备工作台、消息聚合、Recipe版本管理、显示设置等独立入口，不计入132项。

按当前前端页面状态配置：53项“已有专用页面”、41项“配置预览”、12项“说明页面”、26项“当前版本未接入”。这是页面接入分类，不是完成率；不证明真机执行、业务闭环或稳定性。多个专用页面入口可能共用同一组件。库存/发布/订单等线上实际能力还受后端版本、设备和验收状态影响。

## 建议保留在主导航的内容（后续方案，未实施）

- 设备：设备工作台 + 入网绑定 + 远控入口。
- 消息：消息聚合，按设备查看已采集会话；正文完整性仍待真机验收。
- 商品：编辑、列表、导入、分组，以及已接通并验收的闲鱼操作。
- 订单：同步与查看结果统一到一个入口。
- 任务：查看操作是否排队、执行、失败或完成。
- 素材：地址、描述、标签、水印统一管理。
- 设置/高级：显示设置与开发维护用的Recipe版本管理。

帖子与小红书是否常驻，取决于当前是否经营图文业务。未接入和只展示配置的入口建议隐藏，等可用后再开放。

## 明确存在的重复入口

- 闲鱼商品发布：商品管理 / 发布闲鱼，与闲鱼授权任务 / 发布商品，共用 XianyuPublishGoodsView。
- 小红书笔记发布：帖子管理 / 发布小红书，与小红书授权任务 / 发布笔记，共用 PostPublishView。
- 商品信息采集：统计分析 / 采集宝贝信息，与闲鱼授权任务 / 采集宝贝信息，共用 ListingInfoCollectView。
- 设备地址池、描述池、标签池：产品编辑、闲鱼授权任务、系统素材中各有入口，分别共用对应组件。
- 水印：多处入口共用水印组件；商品/帖子所需参数应保留，导航可合并。
- 设备列表和设备工作台：用途部分重叠，但旧设备列表还包含绑定入口，不能简单删除而丢失绑定功能。
- 订单结果：订单管理 / 查看全部订单当前重定向到商品管理的订单标签。

## 系统主页还剩哪些项

设备列表、系统授权、常见问题、常用工具、超级擦亮、建议反馈、公告通知、视频教程。

其中设备列表含绑定能力；系统授权有通用操作映射，不能按标题等同于完整账号管理；其他说明/配置入口不应占据日常操作主导航。建议下一轮将实际必要的设备和授权设置整合，其余暂时隐藏。本次尚未实施这些建议。
