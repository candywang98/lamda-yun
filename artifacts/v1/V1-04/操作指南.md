## 操作步骤

### 步骤 1: 启用 Companion 无障碍服务

**重要**: 此步骤需要在设备上手动完成，无法通过 ADB 自动化。

#### 方法 A: 通过设置菜单（推荐）

1. 在 OnePlus 设备上打开 **设置** 应用
2. 导航路径：
   ```
   设置 → 其他设置 → 无障碍 → 已下载的服务
   ```
   或者
   ```
   设置 → 辅助功能 → 无障碍 → 服务
   ```
3. 找到 **CloudCtl Companion** 或 **Companion Automation**
4. 点击进入，开启服务
5. 阅读权限说明，确认授权

#### 方法 B: 通过 ADB 打开设置页面

```bash
# 直接跳转到无障碍设置
adb shell am start -a android.settings.ACCESSIBILITY_SETTINGS

# 或者跳转到应用详情
adb shell am start -a android.settings.APPLICATION_DETAILS_SETTINGS \
  -d package:com.company.cloudctl.companion
```

#### 验证启用状态

```bash
# 检查是否已启用
adb shell settings get secure enabled_accessibility_services | \
  grep "com.company.cloudctl.companion"
```

如果输出包含 `com.company.cloudctl.companion/.automation.CloudCtlAccessibilityService`，则说明已成功启用。

---

### 步骤 2: 安装目标平台应用

#### 选项 A: 从应用商店安装（推荐）

在设备上打开应用商店，搜索并安装：
- **闲鱼**（优先）- 用于商品发布测试
- 小红书 - 用于图文发布测试
- 抖音 - 用于视频发布测试
- 微信 - 用于公众号测试（可选，因为 V1 使用官方 API）

#### 选项 B: 通过 ADB 安装

如果有 APK 文件：
```bash
# 安装闲鱼
adb install xianyu.apk

# 安装小红书
adb install xiaohongshu.apk

# 安装抖音
adb install douyin.apk
```

#### 验证安装

```bash
# 检查已安装的应用
adb shell pm list packages | grep -E "idlefish|xingin|aweme|tencent.mm"
```

预期输出示例：
```
package:com.taobao.idlefish          # 闲鱼
package:com.xingin.xhs               # 小红书
package:com.ss.android.ugc.aweme     # 抖音
package:com.tencent.mm               # 微信
```

### 步骤 5: 配置 Companion APK 连接

#### 方法 A: 通过应用界面

1. 在设备上打开 **CloudCtl Companion** 应用
2. 找到设置或配置入口
3. 输入 Control API 地址：
   - 如果设备和开发机在同一网络：`http://<开发机IP>:8000`
   - 使用 USB 端口转发：`http://localhost:8000`

#### 方法 B: 使用 ADB 端口转发

```bash
# 将设备的 localhost:8000 转发到开发机的 8000
adb reverse tcp:8000 tcp:8000

# 验证转发
adb reverse --list
```

现在 Companion 可以通过 `http://localhost:8000` 访问 Control API。

### 步骤 6: 执行设备注册

#### 在 Companion 应用中

1. 打开 Companion 应用
2. 点击"注册设备"或类似按钮
3. 输入设备名称（可选）
4. 确认注册

#### 验证注册状态

```bash
# 查询已注册设备
curl http://127.0.0.1:8000/api/v1/devices | jq
```

预期看到设备信息，包含 device_id 和状态。

---

### 步骤 7: 运行健康检查任务

#### 截图任务

```bash
# 通过 Control API 创建截图任务
curl -X POST http://127.0.0.1:8000/api/v1/tasks \
  -H "Content-Type: application/json" \
  -d '{
    "device_id": "<从注册结果获取>",
    "task_type": "screenshot",
    "parameters": {}
  }'
```

#### 检查任务状态

```bash
# 查询任务状态
curl http://127.0.0.1:8000/api/v1/tasks/<task_id>

# 查看设备日志（可选）
adb logcat | grep CloudCtl
```

#### 验收标准

1. ✅ 任务从 PENDING → RUNNING → COMPLETED
2. ✅ 设备成功捕获截图
3. ✅ 截图上传到 Control API
4. ✅ 可以在 API 响应中看到截图 URL

## 快速验证脚本

将以下内容保存为 `verify-device-ready.sh`:

```bash
#!/bin/bash
set -e

echo "=== V1-04 设备就绪验证 ==="
echo ""

echo "1. 检查设备连接..."
adb devices | grep -q "device$" && echo "  ✓ 设备已连接" || (echo "  ✗ 设备未连接"; exit 1)

echo "2. 检查 Companion APK..."
adb shell pm list packages | grep -q "com.company.cloudctl.companion" && echo "  ✓ Companion 已安装" || (echo "  ✗ Companion 未安装"; exit 1)

echo "3. 检查无障碍服务..."
adb shell settings get secure enabled_accessibility_services | grep -q "cloudctl.companion" && echo "  ✓ 无障碍服务已启用" || echo "  ⚠ 无障碍服务未启用（需要手动启用）"

echo "4. 检查目标应用..."
XIANYU=$(adb shell pm list packages | grep "idlefish" || echo "")
if [ -n "$XIANYU" ]; then
  echo "  ✓ 闲鱼已安装"
else
  echo "  ⚠ 闲鱼未安装（可选）"
fi

echo "5. 检查 Control API..."
if curl -s http://127.0.0.1:8000/health > /dev/null 2>&1; then
  echo "  ✓ Control API 运行中"
else
  echo "  ⚠ Control API 未运行"
fi

echo ""
echo "=== 验证完成 ==="
```

运行：
```bash
chmod +x verify-device-ready.sh
./verify-device-ready.sh
```

## 故障排查

### 问题: 无障碍服务无法启用

**可能原因**:
- MIUI/ColorOS 等系统限制
- 需要额外的权限授权

**解决方案**:
1. 检查系统是否有"自动启动"或"后台运行"限制
2. 在"应用管理"中允许 Companion 自启动
3. 检查电池优化设置，允许后台运行

### 问题: 设备无法连接 Control API

**可能原因**:
- 网络不通
- 端口转发未设置
- API 未运行

**解决方案**:
```bash
# 使用 ADB 端口转发
adb reverse tcp:8000 tcp:8000

# 在设备上测试连接
adb shell curl http://localhost:8000/health
```

### 问题: 任务创建后无响应

**可能原因**:
- 无障碍服务未启用
- Companion 应用未在前台
- 设备未注册

**解决方案**:
1. 确认无障碍服务已启用
2. 打开 Companion 应用
3. 查看设备日志：`adb logcat | grep CloudCtl`
