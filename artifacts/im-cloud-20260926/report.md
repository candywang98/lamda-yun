`00000000-0000-0000-0000-000000000001`，当前工作台登录身份映射到租户

不允许移除租户过滤、伪造跨租户身份、修改历史消息归属或直接插库制造验收结果。

获取精确 serial 的本地锁、复核云端占用并确认本地待上传数据可保留。

来源设备和时间。单机与三机状态继续为未通过。

## 兼容与限制

- 默认仍要求平台字段。仅配置的旧闲鱼客户端设备允许省略 `platform`；
  显式 null、其他平台和非白名单缺失字段均拒绝。该临时兼容不算新版 Android 验收。
- 重投同时识别旧服务器去重键，保留历史键及记录不变。
- Jev 观察队列进程内有界，重启或队列满会记录跳过状态；不保证每条都完成分类。
  接收数据先提交，分类失败不影响入库。分类结果只有脱敏日志，未建设持久隔离/复核箱。
- `HUMAN_MESSAGE` 是通知类别推断，不证明真实人类身份。自动过滤仍关闭。
- 本轮实际只读 ADB 列表中 VOG 和 OnePlus 在线，ELE 无 USB transport，但云端认证仍更新。
- 浏览器空间 18 仍已交给用户登录；本轮 HTTP 及静态资源检查不冒充网页视觉验收。
